Docker Backup Template

hAI.FullBackupScript

Wiederverwendbares Bash-Template zum vollstaendigen Sichern von Docker-Containern (Image + Volumes + optionalem DB-Dump) auf ein NAS, inklusive Crontab-Backup.

Ablauf

  1. Volume-Pfade mit find_volumes.sh ermitteln
  2. Platzhalter im Template ersetzen
  3. Testlauf durchfuehren
  4. Als Cronjob automatisieren

Dateien

DateiZweck
scripts/full_backup_template.shHaupt-Backup-Script mit Platzhaltern
scripts/find_volumes.shErmittelt Volume-/Bind-Pfade aller Container
docs/ANLEITUNG.mdSchritt-fuer-Schritt Setup-Anleitung

Schnellstart

chmod +x scripts/find_volumes.sh
./scripts/find_volumes.sh

cp scripts/full_backup_template.sh full_backup_5.sh
nano full_backup_5.sh   # Platzhalter ersetzen

bash full_backup_5.sh   # Testlauf

Cronjob

0 3 * * * /bin/bash /home/Scripts/full_backup_5.sh >> /home/Scripts/full_backup_5.log 2>&1

Vollstaendige Anleitung: docs/ANLEITUNG.md · Repo: GitHub
